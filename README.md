# まさてゃんカメコ

推しの写真をまとめて保存・閲覧できるアイドル写真アーカイブ（PWA）。

- 公開URL: https://yokomizomasaharu-sketch.github.io/kameko/
- 見た目の確認（ログイン不要）: https://yokomizomasaharu-sketch.github.io/kameko/?demo=1
- iPhoneは Safari で開いて「共有 → ホーム画面に追加」でアプリとして使えます。

## v3（2026-11-18）公式FCデジタル写真集風にリデザイン

＝LOVE／iLiFE!／AKB48 の公式サイトを実際に見て、その組版を参考に作り直しました。

- **タイポグラフィ**：Cormorant Garamond（欧文セリフ・同梱）＋ しっぽり明朝（和文見出し）＋ Noto Sans JP（本文）。
  セクション見出しは「01 / PICK UP —— 特集」のように、極小の欧文＋ヘアライン＋和文で組む。
- **配色**：ペールピンク `#FDF6F8` の紙 × 純白 × チャコール `#231F20` × ダスティローズ `#C2587C`。
  グループごとのアクセント色も落ち着いた色に統一（＝LOVE / ≠ME / ≒JOY / AKB48 / iLiFE!）。
- **写真が主役**：角丸と影をほぼ廃止し、写真の上に文字やタグを載せない。写真集のページのように余白を取る。
- **ヘッダー**：`MASATEYAN CAMECO` のブランドタイポグラフィのみ（絵文字なし）。
- **ナビゲーション**：極細ラインアイコン＋ガラス背景のバー（HOME／GALLERY／＋／FAVORITES／MY PAGE）。
  ＊／＋は細い枠のボタンで、浮いたピンクの丸ボタンは廃止。
- **グループ**：文字入りの丸アイコンを廃止。欧文のタブ＋細いインジケーターに変更し、
  自分の写真を設定したときだけ上品な縦長のフォトアイコンが出る（長押しで設定）。
- **ログイン**：公式FCログイン風に刷新（ペールピンクの地・セリフのワードマーク・罫線のフォーム・墨のボタン）。
  standalone 時のメール＋パスワード主導線、Safari誘導、Googleログインは従来どおり。

## 中身

`index.html` / `assets/` / `icons/` / `manifest.json` / `sw.js` はViteのビルド成果物です。
`demo/` はUI確認用のサンプル写真（`?demo=1` のときだけ表示され、実際の写真データには触れません）。
ソースは手元の `work/kameko-inspect/repo` にあり、`npm run build` → `dist/` をこのフォルダへコピーして更新します。

Service Worker のキャッシュ名は `kameko-cache-v4`（v3以前のキャッシュは activate で削除）。

## 機能（v2から継続）

- 複数枚まとめてアップロード（最大300枚・重複スキップ・失敗分だけ再試行）
- サムネイル480px／拡大時だけフル画像1600px、24枚ずつ追加読み込み
- 検索・グループ絞り込み・タグ・グリッド／リスト表示・お気に入り
- グループ／プロフィールのアイコンをスマホの写真から設定（端末内に保存）
- メール＋パスワード／Googleログイン、パスワード設定、ホーム画面追加ガイド
- Firestore（`photos/{id}` サムネ + `photos/{id}/data/full` フル）は変更なし
